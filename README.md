# ESP32 Playground

My small ESP32 experiments while I learn smart hardware, one step at a time.
Each folder is one experiment: code, wiring notes, and a photo.

## Experiments

| # | Experiment | What I learned | Status |
|---|---|---|---|
| 01 | Blink an LED | Upload code to the ESP32 and make an LED blink | ✅ Done — 2026-10-22 |
| 02 | Serial print | Print a line of text to the Serial Monitor | Next |
| 03 | Button & buzzer | Read a button, make a sound | Planned |
| 04 | DHT22 sensor | Read temperature and humidity | Planned |

## Parts I use

- ESP32 dev board
- Breadboard and jumper wires
- LEDs and resistors
- Button module and buzzers

## Rule for this repo

Every experiment gets its own folder (`01-blink`, `02-serial-print`, ...).
Code is uploaded on the same day I make it work — with a photo of it working.
